# CZ_Silicon_Melt_CFD_Dataset
Certified CFD reference data for three Czochralski silicon melt parameter sweeps (crystal rotation, crucible rotation, hot wall temperature), 33 cases total. Geometry and boundary conditions follow Huang et al. (2025), AIP Advances 15(10), 105202. Run in ANSYS Fluent 2026 R1. Intended as training data for surrogate models and PINNs.
